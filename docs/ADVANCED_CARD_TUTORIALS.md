# 新カードのチュートリアル

QQ-0.59.0で追加したレッスン11〜14。ハブのチュートリアル一覧から選びます。
既存の戦闘画面と本物のカード・状態・タイムラインを使います。

## 連携と反響

`prepared_combos`: 集中指令 → ガード → 予約が残っていることを確認 → 反響 → クイックスラッシュ。

- 集中指令は発動時に予約され、ガードや準備カードでは消費されません。
- 反響の発動後に攻撃を登録。1枚の登録から効果が2回発動したイベントを確認して進みます。
- 攻撃強化が両方の実ダメージに適用され、予約と反響は消費されます。登録・スロット解放・再使用は1回です。
- 240HPの標的を使い、先に撃破して実演が途切れることを防ぎます。敵AIは無効です。

## 次の敵カードへの妨害

`hostile_reservations`: 脱力タグ → 再使用ジャマー → 状態欄を確認 → 敵クイックスラッシュ → もう1枚の通常クイックスラッシュ。

- 妨害を付け終わってから敵の攻撃を登録します。同時発動順による成否の揺れを避けます。
- 敵が元から持つ同じGradeの2枚を使い、効果あり／なしを比較します。
- 最初の実ダメージが小さく、再使用が長くなり、次の攻撃には予約が残らないことを確認します。
- 練習内だけ敵の攻撃力を12に設定。両方受けてもプレイヤーは生存します。

## リジェネ

`regeneration`: ナノ再生 → 初回の定期回復 → 応急ジェル → 集中再生 → 3層の確認 → 合算回復 → 全層の終了。

- プレイヤーは20HPから開始し、即時回復と定期回復を区別します。
- 次のカードを使わせる時刻を実際の発動・回復イベントで制御し、3層の有効時間が重なるようにします。
- 回復余地を十分に用意し、HP上限のために回復イベントが消えることを防ぎます。
- 最後は状態の消失まで待ちます。3秒周期・独立した残り時間・上限3層のルールを説明します。

## 無効化と転換

`damage_conversion`: 生命転換 → 敵攻撃で回復 → 効果と再展開待ちの終了 → 防壁転換 → 敵攻撃でシールド → 再度待機 → 疲労と2枚目の生命転換。

- 28HPから開始し、保護が発動してから敵攻撃を登録します。カードを登録しただけでは無効化されない点も案内します。
- 各転換の間は保護・再展開待ちの両方が終了するまで待ち、後の転換が不発になることを防ぎます。
- 疲労は通常通りの5秒詠唱です。約3秒残った時点で停止し、練習用の2枚目の生命転換を登録させます。
- 現在の生命転換の詠唱は1.2秒、保護は4秒。疲労の前後とも保護が残る余裕があります。疲労のスケジュールやダメージを改変して成功させることはしません。
- 疲労までに獲得シールドが自然減少し、無効化されない実HPダメージを確認できます。HPコストも対象外と説明します。

## 安全性と検証

- 説明・カード選択・結果確認中は戦闘時間を停止し、読むのに時間がかかっても状態が切れません。
- 選択できるカードを指定し、実際の発動イベント、回復量、ダメージ無効化などを確認します。
- 敵の登録失敗や、待機中に必要な効果を45秒確認できない場合は再挑戦の案内を表示します。
- 練習の変更は専用UnitStateだけです。Database、実ラン、メタ進行、途中セーブ、ランキングルールは変更しません。
- `AdvancedCardTutorialSmoke`: 日本語・英語 × 更新幅0.05/0.23秒 × 4レッスン、計16回を最初から最後まで実行。実効果、停止、死亡しないこと、進行データの不変を検証します。
- `BattleTutorialSmoke`: 既存を含む全14レッスンを通し実行します。
- `tools/web_advanced_card_tutorial_review.mjs`: 日本語1440×900・英語960×600で、時間スキップやステップ飛ばしをせず、マウス操作で8回通し実行。状態のホバー説明、吹き出しの画面内配置、実結果、一覧への復帰を確認します。
