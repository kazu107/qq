# 戦闘フィールド背景

`QQ-0.58.0`。すべてBlenderで制作したプロジェクトオリジナル素材です。
戦闘ルール・敵ステータス・ランキングルールは変更しません。

## 使用場所

| ステップ / 敵 | フィールド | 主な造形 |
| --- | --- | --- |
| 1–7 | 苔むす時計遺跡 | 小川、崩れた壁、時計、草木 |
| 8–14 | 真鍮の機械工房 | 配管、鋳炉、歯車、格子、金属柱 |
| 15–21 | 亀裂の浮遊回廊 | 浮遊島、結晶、壊れた柱、裂け目の門 |
| 22–28 | 忘れられた時の聖域 | 柱廊、段床、時計の封印、祭器 |
| タイムキーパー | 大時計塔の機関室 | 大時計、振り子、連結歯車 |
| パラドックスコア | 循環する中枢炉 | 三重の軌道輪、結晶炉 |
| アクシオムブレイカー | 崩壊した法則の祭壇 | 漂う石版、発光文字、法則の輪 |
| エタニティゼロ | 終刻の神殿 | 高い柱、二重の時計、冠状の屋根 |

- 無限モードは28ステップごとに地域が繰り返され、第2周以降は追加造形と照明を切り替えます。
- 通常地域・ボスを合わせて16通りの外観。差分用GLBは4種類を共有します。
- アリーナは3戦ごとに地域が変わります。双方が同じラウンド番号を使い、相手や観戦視点には依存しません。
- チュートリアルは時計遺跡に固定。新しいリプレイには背景情報も記録します。旧リプレイは時計遺跡です。
- ショップ、鍛冶屋、回復施設の3キットと4地域を組み合わせた背景12枚を使用します。イベント・危険地帯の入口・マップは地域の全景を使用します。

## ソースと負荷

- 編集可能ソース: `art_src/blender/environment/biomes/*.blend`
- 実行用モデル: `assets/models/environment/biomes/*.glb`
- レンダー背景: `assets/backgrounds/biomes/*.png`（1024×576）
- 制作・ハッシュ・ポリゴン数: `art_src/blender/environment/biomes/manifest.json`
- 全体登録: `data/art_provenance.json`
- 再生成: `blender --background --factory-startup --python-exit-code 1 -t 4 --python tools/blender/build_battle_biomes.py`

共通の7×5床、42×38の地面、既存のカメラ・キャラ配置を維持します。
部品はソースで個別編集でき、実行時は用途別にメッシュを統合します。
背景ごとのリアルタイムの水・流体・ボリューム霧は使わず、浮遊部品のみ低コストで動かします。
PackedSceneと画像は起動時にフレームを分けて先読みし、表示済みフィールドのNodeも戦闘ステージ内に保持します。
非表示ステージの描画とアニメーションは停止します。共有素材の色は書き換えず、照明をステージ単位で変更します。

## 確認

- 開発者モード → 戦闘アニメーションラボ → フィールド / 無限モード差分。
- アートラボのフィールド・無限フィールド差分・施設モデル・背景カテゴリでも確認可能。
- `BattleBiomesSmoke`: 地域・ボス・後続周・アリーナの選択、床/位置不変、再利用、停止、施設画像。
- `tools/web_battle_biomes_review.mjs`: Webの16外観、施設12画面、画面遷移のキャッシュ、狭い画面、開発者セレクター。
