# 未調整カードのGrade調整

過去の個別調整JSON3件を参照し、個別調整済み23枚と最近追加した29枚は維持しました。
再使用時間だけを一括変更した87枚は「個別調整済み」とはみなしていません。
今回の対象は残る70枚のGrade 1〜5です。Grade 0、コスト、対象、投入枚数、
連鎖上限、シールド支払い、ボス専用3枚、鍛冶屋の上限Grade 3は維持します。

## 基準

- 通常〜エピックの攻撃は基本値の約30%を各Gradeで追加。シールドは約28%、回復は約30%。整数化して最低増分は攻撃・回復1、シールド2です。
- 複合効果の多いレジェンダリーは攻撃・シールド・回復を約18%ずつ追加し、単機能カードとの差を残します。条件付き追加ダメージは約25%ずつ追加します。
- 詠唱は基本の長さに応じて毎Grade 0.1/0.2/0.3/0.6秒短縮。再使用は0.4/0.6/1/1.2秒ずつ短縮します。Gradeの最低値は詠唱0.6秒、再使用4秒です。
- 単体遅延は0.7秒、全体遅延は0.4秒ずつ増加。単体加速は0.5秒、全体加速は0.3秒ずつ増加します。停止・逆流は基本時間の10%、最大0.5秒ずつ増加します。
- 再使用短縮効果は全体0.4秒、単体は基本量の15%（最低0.6秒）ずつ増加。効果量と自分自身の再使用時間を区別しています。
- 出血は以前リワークした威力の成長1/1/2/2/3/4を維持します。持続は毎Grade基本の5%（最大2秒）、その他の状態は10%（最大3秒）追加します。
- 永続強化は自分・特定カードに20%、全体に10%ずつ追加。詠唱・再使用の負の補正は負のまま強くします。攻撃・速度の弱体化もマイナス方向に強化します。

## 例（Grade 0 → 1 → 2 → 3 → 4 → 5）

| カード | 要素 | 値 |
|---|---|---|
| オートタレット | ダメージ | 2 → 3 → 4 → 5 → 6 → 7 |
| オートタレット | 詠唱 | 3 → 2.8 → 2.6 → 2.4 → 2.2 → 2秒 |
| エントロピーアーマー | シールド | 13 → 17 → 21 → 25 → 29 → 33 |
| リサーキュレート | 再使用短縮量 | 12 → 13.8 → 15.6 → 17.4 → 19.2 → 21秒 |
| クロノスタシス | 停止時間 | 3 → 3.3 → 3.6 → 3.9 → 4.2 → 4.5秒 |

調整前の定義と全70枚の各Gradeの実数値は `tests/fixtures/remaining_grades_0_56_0.json`、
再現可能な計算は `tools/tune_remaining_grades.mjs`、実際のゲーム数値は `data/cards.json` の
`grade_overrides` に保存しています。今後ラボで個別調整する際にも各Gradeを独立して編集できます。
