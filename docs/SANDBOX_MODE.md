# サンドボックス

メインメニューから利用できます。開発者モード・カードや遺物の解放は不要です。

## 準備

- 自分と敵のモデル、ステータス、初期シールド、スロット、ロードアウト上限を設定します。
- カードはアイコン一覧の検索・レア度・種類から追加します。片側64枚まで、同じカードも別々のGrade（基本〜+5）を指定できます。敵・ボス専用カードも利用できます。
- 遺物は片側16種類までです。ラン進行・施設・報酬を条件とする遺物は通常ランの条件を満たさないため、戦闘のみのサンドボックスでは発動しません。
- AI、疲労、不死、ボスの固有行動、無限強化、Seed、フィールドを設定できます。無限強化は敵の設定値を基準に通常の無限強化倍率を適用します。
- 「ランからコピー」は現在のラン、なければ中断した通常ランの編成を読み取ります。元のランは変更しません。
- 名前付きプリセットは20件までです。最後の設定も保存します。この端末・ブラウザのプロフィール別保存で、現時点ではクラウド同期しません。

## 戦闘

通常のBattle画面を使用します。カードか開始ボタンで始めます。右上のサンドボックスパネルを展開すると、一時停止、0.25〜4倍速、0.1秒・1秒送り、両陣営のHP全快・状態解除・シールド解除・再使用リセット、AI、敵カード登録、統計、再戦、設定へ戻る操作ができます。統計を開くと停止します。

不死はHP1で生存します。シールド消費などのカード使用条件は無視しません。状態解除は状態・予約・反響・次の攻撃倍率を消し、カード自体の永続的な一時強化は再戦でリセットします。自動投入などでタイムライン256枚や安全上限に到達した場合は停止します。

## データ隔離

`SandboxConfig` が設定を検証し、実セーブとは別の `RunState` を両陣営に生成します。`SandboxSession` は実行中の設定のみを持ち、アカウント切り替え時に破棄します。戦闘結果は `sandbox=true` / `achievement_eligible=false` となり、`Game.complete_battle` は適用しません。ランキングコマンドも記録しません。

通常ラン・アリーナの中断データ、メタ進行、実績、ランキングは変更しません。保存対象は設定だけで、開始や再戦時にも実ランを差し替えません。ネットワーク対戦接続中は利用できません。

## 検証

- `res://tests/SandboxModeSmoke.tscn`: 両陣営、個別Grade、遺物、強化上限、AI、再帰投入、通常データ隔離、プリセット、プロフィール境界。
- `node tools/web_sandbox_review.mjs`: Web Layout Review出力を使用し、実際のクリック・入力から編成、プリセット、戦闘、統計、勝利、再戦、解像度・言語を検証します。
