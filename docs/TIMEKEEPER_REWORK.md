# タイムキーパーのDPSチェック型リワーク

QQ-0.36.0 / 2026-10-13

## 編成と進行

通常ステップ7のタイムキーパーは、HP77・攻撃力6・速度6を維持します。従来の6枚と周期的な遅延パッシブを、以下の専用3枚に置き換えました。他のボスは変更していません。

| カード | 詠唱 | 再使用 | スロット | 効果 |
| --- | ---: | ---: | ---: | --- |
| 終刻の一撃 | 40秒 | 8秒 | 2 | 基礎25ダメージ。中断不可。遅延・停止・逆流は有効 |
| 時計仕掛けの増幅 | 3秒 | 8秒 | 1 | 次に解決する攻撃カード1枚を2倍化。中断可能 |
| 時の刻印 | 2秒 | 8秒 | 1 | プレイヤーに脆弱を12秒付与。中断可能 |

戦闘開始時刻0で一撃を登録し、6秒後に増幅を登録します。刻印は一撃の**実際の残り詠唱時間が8秒以下**になったときに登録します。無干渉なら増幅が約9秒、刻印が約34秒、一撃が約40秒に解決し、再使用後の約48秒で次の周期を開始します。シミュレーションの刻み幅による微差があります。

増幅・刻印は各周期でそれぞれ一度だけ登録します。中断に成功したカードを、その周期で即座に再投入することはありません。遅延後も刻印の登録時刻は一撃の残り時間に追従します。ただし刻印発動後に一撃を遅らせれば、脆弱を失効させることもできます。

## ダメージ規則

倍化は、登録順ではなく**次に解決する攻撃カード**に適用されます。既に詠唱中の一撃にも有効です。

`(カードの基礎ダメージ + 現在の攻撃力) × 2 + 対象の脆弱補正`

- 無干渉の初回は `(25 + 6) × 2 + 3 = 65`。シールドが肩代わりします。
- 増幅を中断すると `25 + 6 + 3 = 34`。
- 弱化中は攻撃力が4になり、刻印込みで `(25 + 4) × 2 + 3 = 61`。
- 複数ヒットは同じカードの全ヒットに適用し、カード1枚で一度だけ消費します。完全にシールドで防がれても消費します。
- 増幅の重複は4倍などにならず、2倍のままです。時間では失効しません。
- 出血・疲労・遺物によるダメージ、非攻撃カードでは消費しません。自動投入された攻撃カードには適用されます。

強化された無限モードの敵には既存のステータス・カードGrade補正が適用されます。一撃のGrade補正は基礎ダメージ+0/+3/+6/+9です。40秒で必ず終了させる制限や最終判定は追加していません。従来の疲労システムはそのままです。

## UI・所有権・キャッシュ

倍化は専用の金色アイコンと `x2` で3Dステータスプレートに表示し、ホバーで規則を説明します。タイムライン上部には残り詠唱時間と現在の威力を表示します。威力は攻撃力・倍化・脆弱を含む**シールド適用前**の値で、「倍化込み」と明記します。カードのツールチップと効果チップも攻撃力・倍化を反映します。

専用カードは `data/boss_cards.json` に分離し、通常カード93枚の図鑑・解放・ショップ・報酬・プリセット・オンライン用デッキには入りません。直接のプレイヤー投入も拒否します。スナップショット・リプレイに倍化状態を保持し、旧データは未強化として読み込みます。オンライン互換性判定のコンテンツハッシュにも新定義を含めます。

カード3枚と状態1枚は隔離したBlenderプロセスで制作しました。原本は `art_src/blender/cards/timekeeper_boss.blend`、生成スクリプトは `tools/blender/build_timekeeper_boss.py` です。既存UIキットの材質・プリミティブを共有しつつ、それぞれ長針の大剣、二つの歯車、時計の封印という異なる構図です。PNG・原本・manifestのハッシュと保存原本の再読み込みを検証済みです。新画像も既存のネイティブ起動時キャッシュ／Web遅延読み込みの対象です。

発動SEは既存の大技・時間操作・弱化系SEへ明示的に割り当て、SEラボにも3枚を追加しています。

## 確認方法

設定で開発者モードを有効化し、ハブのデバッグ戦闘ラボで「タイムキーパー」を選択してください。実際のロードアウト・Gradeを指定できます。戦闘中の開発者パネルには「ボス倍化 x2」「ボス倍化を解除」があり、予測値と状態表示を即座に比較できます。オンライン中は使用できません。

`TimekeeperReworkSmoke` は初回／第2周期、スロット、中断、遅延・停止・逆流、倍化消費、複数ヒット、弱化・完全シールド防御、所有権、旧／新スナップショット、5状態アイコンを確認します。7スターターの初期ロードアウトを自動操作し、300秒の検証用上限以内に決着することも確認します。この上限はゲーム本体には適用しません。関連する既存テストも実施しました。`tools/web_timekeeper_review.mjs` はWeb Layout Review出力を実ブラウザで実行し、1440×900・960×600・900×1200の表示、ホバー、開発者操作、予測値、65ダメージと第2周期を確認します。ログ・画像は `tools/.local/timekeeper-tests` と `tools/.local/timekeeper-browser` です。

これらは機能の回帰テストであり、全ロードアウトの勝率や人間プレイでの難易度調整を保証するものではありません。

初期デッキ・seed4242・メタ強化なし・既存の汎用自動操作という条件では、ヴァンガードが34.25秒、バランスが65.55秒で勝利しました。他の5構成は40.05〜88.10秒で敗北しています。これはステップ7までの報酬・強化を取得していない条件での単一サンプルであり、人間の操作や実際のラン完走率とは別の値です。
