# タイムライン範囲外のカード表示

QQ-0.36.2 / 2026-10-15

## 固定目盛り

最大目盛りは、戦闘開始時の両者のロードアウトから求めた詠唱時間を、従来どおり4の倍数へ切り上げます。疲労の詠唱5秒を最低基準に含めます。`timeline_scale_excluded: true` のカードは計算から除きます。現在、この設定があるのはタイムキーパーの「終刻の一撃」だけです。

バランスの初期デッキでタイムキーパーと戦う場合、目盛りは40秒ではなく `0 / 2 / 4 / 6 / 8秒` になります。通常の長い詠唱カードは引き続き計算に含め、たとえばフォーティファイの16.8秒を持つ場合は最大20秒になります。遅延や状態変化で戦闘中に目盛りを広げません。レア度・Gradeの複製でも除外設定を保持します。

## 表示と補間

実際の残り時間を `r`、表示する最大目盛りを `H` とすると、範囲外カードの倍率は `0.35 + 0.65 × H / r` です。範囲内では1倍です。範囲外でも35%より小さくならず、8秒目盛りなら40秒で48%、16秒で67.5%、8秒で100%となります。

カード全体を均等に縮小するため、絵は正方形のまま、コスト・秒数・効果・名前も一緒に拡大縮小します。縮小中は右端の領域に収め、最大目盛りに達すると通常位置へ連続的に合流し、以降は残り時間に比例して左へ移動します。数字は丸めた目盛りではなく、実際の残り秒数を示します。ホバー説明と右クリックによる説明切り替えは従来どおり使えます。

遅延では既存の0.5秒補間に従って移動とサイズが変化し、その間に経過する時間も含めます。停止・逆流は既存の連続時間補正を使い、遅延補間を重ねません。加速して範囲へ戻ったカードと、別のカードに再利用される表示ノードも通常倍率へ戻ります。プレビューの透明度サイクルは変更しません。プレイヤー・敵・疲労・プレビュー・リプレイで共通です。

実際の発動時刻・ダメージ・ソート順・倍率強化・通信状態は変更しません。タイムライン枠とカードの論理サイズは固定し、表示上の倍率だけを変えるため、登録や拡大によるレイアウトの揺れを防ぎます。

## 手元での確認

開発者モードを有効にし、ハブのデバッグ戦闘ラボでタイムキーパーを選びます。開幕の大技が右側で小さく表示され、発動まで8秒になると通常サイズになります。開発者パネルの「敵カードを+10秒遅延」を押すと、大技だけでなく増幅など通常の短い詠唱カードも、範囲外に移動して小さくなる様子を確認できます。この操作はオンライン中には使えません。

`TimelineOverflowSmoke` は目盛り除外とGrade保持、通常の長詠唱、拡大の単調性、境界での位置・サイズの連続性、遅延・逆流・停止、疲労・プレビュー、ノード再利用、枠の固定、リプレイを確認します。`tools/web_timekeeper_review.mjs` は1440×900・960×600・900×1200で、開幕の縮小・段階的拡大・範囲内の左移動・開発者遅延・通常カードの範囲外表示と、既存の251ダメージの戦闘サイクルを確認します。

ローカルのテストログは `tools/.local/timeline-overflow-tests`、ブラウザの画像・結果は `tools/.local/timekeeper-browser` に出力します。
