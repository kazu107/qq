# UIアイコン監査と配置

2026-10-12 / QQ-0.34.0

## 判断基準

全画面の構築コード、共通カード・遺物・バナー・操作部品を監査した。既存のHP、ゴールド、カード効果、4状態、施設、遺物は再利用し、意味が不足していた操作とナビゲーション36種を追加した。意味が曖昧な選択肢、取り消せない操作、チュートリアルの説明は文字を残す。状態説明やカード効果の長文をすべて記号だけにする変更ではない。

アイコンだけの操作にはツールチップを残し、売却額・メタポイント・残り時間などの数値は消さない。状態は暗さではなく残り秒数で表し、色だけを識別手段にしない。

## 画面別の対応

| 画面・共通部品 | 対応 |
| --- | --- |
| ハブ | アリーナ、Web対戦、無限、チュートリアル、メタ進行の専用絵。メタポイントをアイコン＋数値に。主要遷移ボタンの文字は保持 |
| 設定 | 音・画面の見出し、設定リセット・戻るに専用絵。チェック・音量・言語・解像度の文字は保持 |
| デッキ選択 | 戻る、開始に操作絵。キャラ・デッキ名・効果は保持 |
| マップのロードアウト | 装備、カード右上の取り外し、売却、プリセット保存・適用・削除をコンパクト化。売却額は表示、所持数・装備数は既存絵を共有 |
| アリーナ準備 | 同じ装備・売却・プリセット操作。ショップ再抽選、次の戦闘に絵。オンライン参加者は勝利・敗北の絵＋数値、準備状態は絵＋黄/緑の文字 |
| 戦闘 | ログをアイコンボタンに。開始/取り消しは再生/停止絵＋文字。3Dプレートの状態名を4状態アイコン＋秒数に変更し、同じyawとライブ詳細を維持 |
| タイムライン・カード | 既存コスト、詠唱/再使用、効果、陣営、疲労の絵を共有。カード名・重要な数値は保持 |
| 通常・アリーナ報酬 | 再抽選、スキップ、受け取りに絵。HP、ゴールド、遺物・カードは既存絵を共有。報酬内容は保持 |
| イベント・ショップ・鍛冶・回復・危険地帯 | 選択肢内のHP/金/カード/遺物は既存絵。鍛冶強化に上向き矢印を追加。自由文章・代償・選択肢名を保持し、専用の子要素があるボタンに重複絵を挿入しない |
| メタ進行・実績 | ポイントを絵＋数値に。解放/受け取りに鍵/贈り物を追加。実績名・説明・進捗・報酬は保持 |
| カード図鑑 | ポイントを絵＋数値に。絞り込み・検索・解放、ハブ・メタへの遷移に絵。フィルタの種類名は保持 |
| Webロビー | 作成/参加、準備、開始、退出、詳細に絵。BOTにロボット絵、役割選択に対戦/観戦絵。役割・接続状態・部屋名・ルールは文字を保持 |
| ラン結果・戦闘詳細 | 勝利/敗北絵、再挑戦・ハブ・リプレイ・閉じるに絵。統計の種類やグラフは保持 |
| リプレイ | 再生/一時停止、次の解決をアイコンのみ＋ツールチップに。速度・時間・ファイル名は保持 |
| チュートリアル | 選択・開始・続行・終了の操作絵。説明と吹き出しは文字を保持し、状態は本番3Dプレートと共通 |
| 開発者パネル・SE/アニメーション/自動戦闘ラボ | 保存/出力、再生/停止、再挑戦、閉じる、戻るを共通ルールで装飾。コマンド内容や測定結果は保持 |
| アート確認ラボ | 追加36種を来歴付きで表示し、原本パスと実寸を確認できる。設定で開発者モードを有効にして開発者パネルから開く |
| ロード画面・ブランド | 既存SVGとロード状況を維持。無意味な追加絵は入れない |

## 追加素材

全36種は`assets/icons/ui/{id}.png`、64x64 RGBA。ツールチップの日本語/英語定義は`data/ui_action_icons.json`。

| 系統 | ID |
| --- | --- |
| 移動・進行 | `home`, `back`, `next`, `exit`, `infinity` |
| 再生・記録 | `play`, `pause`, `restart`, `log`, `info`, `close`, `save`, `load`, `delete`, `export` |
| カード・報酬 | `equip`, `unequip`, `sell`, `upgrade`, `unlock`, `claim`, `reroll` |
| 検索 | `search`, `filter` |
| モード・参加 | `tutorial`, `arena`, `online`, `spectator`, `ready`, `waiting`, `bot` |
| スコア・設定 | `trophy`, `defeat`, `meta_points`, `sound`, `display` |

剣/盾などの既存部品と金属・エナメル材質を共有しつつ、家、矢印、冊子、鍵、贈り物、砂時計、ロボットなどの固有形状を作った。既存のBlender MCPセッションは変更せず、独立したバックグラウンドプロセスで制作した。

原本: `art_src/blender/ui/qq_ui_actions.blend`。36個の編集可能なアセットコレクション、共通カメラ・照明を保存。台座・文字・他者画像を含まない1024px透過レンダーから縮小する。中間画像・BlendをゲームのPCKへ含めない。元からある4状態画像は重複制作せず共有する。

## 再生成・キャッシュ

```powershell
& $Blender --background --factory-startup --threads 4 --python-exit-code 1 --python tools/blender/build_action_icons.py
python tools/finalize_action_icons.py
& $Blender --background --factory-startup --threads 4 --python-exit-code 1 --python tools/blender/build_action_icons.py -- --validate-only
python tools/finalize_blender_assets.py --date 2026-10-12
```

`build_ui_batch.py`の部品ライブラリを使用する。ハッシュ、透過、寸法、重複、24pxの輪郭、保存原本の再読み込みを検証する。比較画像は`art_src/blender/previews/action_icons_24px.png`。BlenderにPillowを導入する必要はなく、縮小はシステムPython/Pillowで行う。

`StatIconFactory`は起動時に49 UI画像をRAMキャッシュし、同じTexture2Dを共有する。ボタンはノード追加時の一度だけ意味に応じて装飾し、毎フレーム全画面を検索しない。3D状態セルも生成後は再利用する。UI追加時は`UiIconHelper.decorate`で明示指定を優先し、データIDを含む解放/実績ボタンはID由来の誤判定を避ける。

## 関連検証

`UiActionIconsSmoke`で36 PNGとキャッシュ、操作意味、金額とツールチップ、専用選択肢の重複回避、4状態の角度・秒数・ライブホバー・消滅を検証する。ブラウザ検査は`tools/web_action_icons_review.mjs`。Web Layout Review専用ビルドを使い、主要13画面と3種類の画面寸法、4人の準備一覧、実マウスによる3D状態ホバー・秒数更新・マウス離脱を確認する。本番ビルドには検査用ドライバーやテスト画面を含めない。

今回のローカル確認: 関連Godotテスト27件、専用ブラウザ検査13画面、一般レイアウト検査84画面/寸法の組み合わせ、アートラボの新アイコン詳細、起動ロード検査を通過。プレイヤーの実セーブとは別のプロファイルを使用した。透過PNG36種の合計は102,388 bytes、Blend原本は189,806 bytes。通信・ゲームバランスの内容ハッシュは`b548a871cae6`のままで、ルール変更はしていない。
