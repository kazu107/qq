# UI Copy

- Prefer a title, actionable controls and current values over subtitles and repeated instructions.
- Put optional explanations in localized tooltips near the relevant control.
- Keep card/relic effects, tutorial guidance, errors, costs and data-safety warnings visible where needed.
- Keep chart legends that identify otherwise ambiguous colors or series.
- Use proper hanging lists for release notes, not inline hyphen prefixes.
- UI-only copy/layout updates do not change the ranked gameplay revision or season.
