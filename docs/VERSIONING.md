# バージョン管理

このゲームでは `QQ-MAJOR.MINOR.PATCH` 形式の独自バージョン番号を使用します。

- `MAJOR`: セーブデータや通信プロトコルなどに互換性のない変更を行ったときに上げます。
- `MINOR`: 新機能、カードや遺物などのコンテンツ、画面やUIを追加したときに上げます。
- `PATCH`: 不具合修正、表示調整、バランス調整を行ったときに上げます。

## 情報源

現在の番号とゲーム内の更新履歴は [`data/version_history.json`](../data/version_history.json) を唯一の情報源とします。コード、データ、UI、バランスのいずれかを変更するたびに、少なくとも `PATCH` を更新してください。

## 過去履歴

正式な番号運用は `QQ-0.10.0` から開始しました。`QQ-0.9.2` 以前はGitのコミット履歴を機能単位でまとめ直した推定バージョンであり、ゲーム内でも「推定」と表示します。日付と変更内容は実際のコミットを基にしていますが、当時その番号で公開されたことを示すものではありません。

## 更新手順

1. `current_version` を変更内容に合う番号へ更新する。
2. `releases` の先頭へ同じ番号、日付、日本語と英語の変更内容を追加する。
3. 関連テストとWebビルドを実行する。
4. 変更をコミットしてGitHubへpushする。

通信プロトコルの番号はゲームバージョンとは別に管理し、互換性に影響する場合は両方を更新します。
