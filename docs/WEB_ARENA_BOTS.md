# Webアリーナのbot

QQ-0.33.0 / 2026-10-12

## 操作

1. Web対戦で部屋を作成します。
2. ロビーのbotデッキ欄で、ランダムまたはスターターを選び「botを追加」を押します。
3. 削除はbotの参加者枠にある×ボタンです。追加・削除はホストだけが行えます。
4. 人とbotの合計が設定人数（2/4/6/8）に達し、人が準備完了になったら準備フェーズを開始できます。

ホスト1人とbot1人だけでも遊べます。観戦者は人数枠を消費しません。ホストを観戦者に切り替えれば、bot同士の試合も観戦できます。

開発者モードには「botで空き枠を埋める」操作があります。追加要求は1件ずつ承認を待つため、サーバーの人数上限を越えません。

## 進行

- botは常にロビー準備完了です。
- 準備フェーズでは、自分のゴールドで最大4商品の購入、装備、通常・特別報酬の選択を行います。無料の追加資金、メタ強化、開発者操作は使いません。
- 人対botは人の戦闘開始を待ち、3秒カウントダウン後に戦います。bot同士は自動でカウントダウンします。
- 戦闘はホストの既存`EnemyAI`を各botの陣営に割り当てます。詠唱・CD・スロット・シールド消費は通常の戦闘エンジンが検証します。
- 全試合終了後、botは結果確認を自動で行います。人は従来通りボタンを押して進みます。全対戦者がbotなら自動で進み、観戦者に勝敗やHPを加算しません。
- 何先、初期ゴールド・HP、商品数・価格、特別報酬間隔などは同じ部屋ルールを使います。

AIは標準の簡易方針です。難易度・思考方針の設定、ホスト引き継ぎ、切断者をbotへ置換する機能は今回の対象ではありません。

## 実装

botのIDはサーバーが発行する予約領域（1,000,000,001以降）です。botはWebRTCピアではなく、部屋のbot台帳だけに登録します。対戦者数には数え、通信・リプレイの送信先からは除外します。

サーバーが追加・削除を承認してから、ホストが公開プロフィールへ反映します。参加・再接続の予約・botは同じ人数上限を使うため、参加と追加の競合で席が重複しません。試合中の変更はホスト側とサーバー側の両方で拒否します。

`ArenaBotController`はカード画像を読み込まず、キャッシュ済みの定義と通常の購入・装備・報酬APIを使います。準備処理は1回の更新で1botに限定します。各試合のAIはその試合のエンジンだけを操作し、他組のHPや勝敗を変更しません。

通信プロトコルは13です。古いクライアントの部屋は互換性フィルターで除外します。参加者は同じ最新版へ更新してください。

## テスト

```powershell
node --test server/server.test.js
godot --headless --path . tests/WebBotsSmoke.tscn
godot --headless --path . --export-release "Web Validation" build/web-validation/index.html
node tools/web_bots_e2e.mjs
```

`WebBotsSmoke`は人数、RPC送信先、準備、購入、開始待ち、AI、報酬、結果確認、観戦者を検証します。サーバーテストは権限、席の予約、満員、試合中拒否、観戦参加、削除後の人の参加を検証します。Web E2Eは人+bot、2人+2bot、観戦ホスト+2bot、ゲスト再接続を検証します。

ローカル検証結果: サーバー9テスト、WebBotsSmoke（8人・全7スターターを含む）、関連のアリーナ/通信/ローカライズ/表示テスト、Web bot E2Eの3構成が成功しました。`web_bots_layout_review.mjs`で1440x900、960x600、900x1200のロビー表示も確認し、範囲外要素・スクリプトエラーは0件でした。

bot同士の戦闘は、強制決着を使わないシミュレーションでも最後まで進むことを確認しました。

既存の`web_multiplayer_e2e.mjs`も成功しました。人だけの2人/4人対戦、観戦、再接続、別試合のHP分離、疲労による同時決着、結果待ち、ホスト切断の挙動を維持しています。

混在する4人対戦の次ラウンドで、人が敵側・botがプレイヤー側になる場合もWeb E2Eで確認しました。勝敗は正しい対戦者へ加算され、準備へ戻る際にローカルのRunStateも同期します。

公開後は`web_bots_public_smoke.mjs`でHerokuのbot操作・人数・試合中ロックを検査します。実際のゲームとは異なるビルドハッシュの確認専用ルームを使用し、終了時に退出するため通常の部屋一覧には表示されません。
